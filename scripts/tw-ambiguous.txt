# 繁簡共用歧義字（簡體偵測的誤報來源）
#
# 偵測「檔案是否還有簡體殘留」時，本專案用 OpenCC s2t 當探針：
# 逐字比對，凡 s2t 想改動的字元就視為可疑。
#
# 但下列字在**繁體中本來就合法**，s2t 仍會想把它們改成另一個繁體字
# （一簡對多繁時挑錯）。例如：
#   台 → 臺（「台灣正體」是對的，不該變「臺」）
#   系 → 繫（「太陽系」是對的，不該變「太陽繫」）
#   干 → 幹（「干擾」是對的，不該變「幹擾」）
#   文 → （「文件」在台灣指 document，正確）
#
# 偵測時忽略這些字元。若某檔案被 s2t 改動的字元「全部」落在此清單內，
# 就判定為不含簡體、跳過轉換 —— 這一步是安全關鍵：誤判成「含簡體」
# 會讓 s2twp 對已正確的繁體內容做破壞性重轉。
#
# 格式：每行可放多個字元，# 之後為註解，空白會被忽略。
# 遇到新的誤報時把該字元加進來即可。

台系干只后里云面几谷借卷曲制志致胡朱划回准板表折征           # 常見一簡多繁

于丑丰占尸扎余杰游                        # 姓氏或古義在繁體中合法
                                        # 游：上游/游泳（非「遊」）；余：姓氏/我；杰：人名
#
# ⚠ 只放「在繁體中確實合法」的字。像 发/当/复/别/冲/担 這些純簡體字
#   若被加進來，真正的簡體殘留就會被漏報。
